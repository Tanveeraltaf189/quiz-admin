AI marking
Choose which AI marks the written answers. If your main AI is busy or fails, the next ones in the list are tried automatically. API keys are kept in Supabase secrets and never appear on this page. MCQs are always marked from your answer key, not by AI.
How to add a key
1. Get an API key from the AI's website. 2. In Supabase open Edge Functions, then Secrets, and add the key with the exact name shown under each AI above (for example GROQ_API_KEY). 3. Come back here and press "Check keys again": the AI shows "ready". 4. Press Test to try it. The order above is the order the AIs are tried when the main one is busy.

Update popup for students

Steps: 1) If you changed app code, publish it first in Termux with eas update --branch preview --message "...". 2) Press Show update popup here. Students then tap Update now, and the app updates itself. If that fails, it opens the APK link below.
